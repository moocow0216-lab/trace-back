🔐 帳號管理（後台）

每個帳號用 Bitunix UID 登入，第一次登入要綁定 Google 信箱和手機號碼。👑 擁有者 只有一個人，所有功能都能用（掃描條件、回測、結算、改任何人的密碼、轉讓擁有者）。管理員 可以建立帳號、「查看」每個帳號、把別人改成管理員或一般、重設綁定、強制登出、刪除帳號，但不能動擁有者，也不能改別人的密碼。一般 只能設定自己的 API、Discord 和交易參數。沒有任何人能動別人的倉位和資金。

🧪 7 天試用申請

有人在登入頁按「申請 7 天試用」就會出現在這裡。開通後才能登入，可以用一般用戶的所有功能和特級進場；到期自動停止交易、平掉系統開的單、刪除帳號和 API。申請紀錄永遠保留。重複欄會比對每一筆申請的 UID、信箱、電話，跟之前所有試用申請和現有帳號比對。

👑 所有帳號的自動交易

一鍵讓所有帳號一起暫停或開始。暫停後已經開著的單照常管理（鎖利、失敗線、到期）；開始只會開有設定 Bitunix API 的帳號。每個人的 Discord 都會收到通知。

「全部開始」只會恢復被「全部暫停」停掉的帳號；在那之前就已經暫停的（例如他自己按了暫停）維持暫停。🗡 特級交易另外開關，規則一樣，而且只會恢復有特級咒具權限、有設定 API 的帳號。

👑 轉讓擁有者
