📈 我的交易設定
💸 收回資金（一般交易）
把一般交易「目前」的錢收回來：只改目前的金額，盈虧率、資金曲線、成功率都不變。全部收回後一般交易會暫停；之後重新設定投入資金就能再開始（收回的紀錄會清掉）。有持倉時，持倉之後的盈虧會繼續算進來，建議先平倉再收回。
🗡 特級交易設定
💸 收回資金（特級交易）
只用在 🗡 特級交易，跟上面的一般交易分開：投入資金、單日虧損上限各算各的。同一個幣出現反方向的特級咒具訊號時會反手（只反手特級交易自己的單，不動一般自動單和手動單）。改停損線會一起更新交易所上特級單的止損。
🔍 掃描條件（全站共用，只有擁有者看得到、能改）
偵測的五項指標：合約 CVD、未平倉合約、現貨 CVD、現貨 Delta Bars、合約 Delta Bars（成交量不列入判斷）。每項跟該幣自己過去 7 天比較，z 值超過門檻就算異常。改了之後，新的掃描馬上照新條件；回測要重新跑才會照新條件。
💰 AWS 帳單提醒（連上伺服器後可以設定）
伺服器讀不到 AWS 帳單，是用「主機建立日＋90 天」推算免費期，請跟 Lightsail 主機頁面上的建立時間對一下。會在免費期結束前 7 天、前 1 天、結束當天，之後每月 1 號，早上 10 點（台北）傳到 Discord。

📈 BTC 急漲急跌統計

按下去伺服器會抓過去 90 天 BTC 每分鐘的價格，算「幾分鐘內漲跌超過幾 %」多久發生一次，以及發生後 BTC 是繼續衝還是拉回來。大約 1～2 分鐘，可以關網頁。

💼 我的 Bitunix 持倉
投入資金：例如帳戶有 153U、這裡填 100，自動交易只會用這 100U（加上它自己賺的、扣掉它自己虧的）來下單，用完會自動暫停；實盤統計也從 100U 開始算。注意全倉模式下，交易所還是用整個帳戶當保證金，極端行情時帳戶裡其他的錢也可能被拖累。
保證金模式：全倉。出場規則用「⚙ 浮盈／槓桿設定」裡的成功線、失敗線、出場方式和最長持有時間。開倉單會同時掛交易所止損（失敗線）。伺服器重新啟動後，自動交易一律先暫停。

🔐 帳號管理（後台）

每個帳號用 Bitunix UID 登入，第一次登入要綁定 Google 信箱和手機號碼。👑 擁有者 只有一個人，所有功能都能用（掃描條件、回測、結算、改任何人的密碼、轉讓擁有者）。管理員 可以建立帳號、「查看」每個帳號、把別人改成管理員或一般、重設綁定、強制登出、刪除帳號，但不能動擁有者，也不能改別人的密碼。一般 只能設定自己的 API、Discord 和交易參數。沒有任何人能動別人的倉位和資金。

👑 所有帳號的自動交易

一鍵讓所有帳號一起暫停或開始。暫停後已經開著的單照常管理（鎖利、失敗線、到期）；開始只會開有設定 Bitunix API 的帳號。每個人的 Discord 都會收到通知。

「全部開始」只會恢復被「全部暫停」停掉的帳號；在那之前就已經暫停的（例如他自己按了暫停）維持暫停。🗡 特級交易另外開關，規則一樣，而且只會恢復有特級咒具權限、有設定 API 的帳號。

👑 轉讓擁有者

轉讓後你會變成灰色管理員，對方變成擁有者（AWS 提醒、共用的訊號規則也跟著換成對方的）。會寄驗證碼到你綁定的信箱，輸入正確才能轉讓；對方必須已經完成綁定。
